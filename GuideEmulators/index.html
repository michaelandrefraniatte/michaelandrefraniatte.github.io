Emulators

What Emulators Working

For SNES roms I tested snes9x, for GameBoy roms I tested SameBoy, for GameBoy / GameBoy Color / GameBoy Advance roms I tested mGBA, for MageDrive roms I tested Kega Fusion. All are running. I've not tested RetroArch but under Steam, there are all addons for playing all of that roms.

Where to Have Roms

Under here, you can download a file for each console to open with qBitTorrent. You need to unzip roms if your emulator cannot open directly roms in zip folder. I made a tool for it named rmozo. After extracting roms, you need to delete all files related to rmozo and also zip files. You can set the filter of your roms folder to file type in order to delete all files once, then empty your recycle bin.

Which Emulator are Zip Compilant

I tested snes9x and Kega Fusion, both are working with ziped roms. I tested SameBoy and mGBA, both need to unzip roms. Prefer to place each console's roms in different folder allocated for each console under the dedicated emulator's folder.

Nice Features

I made a tool to have an overlay named EmulatorAmbiLight. I also made another tool for fullscreen named EmulatorFullScreen, but prefer use inner settings of the emulator. There are some address table to create cheats, more easy than CheatEngine, or you can use my tool named EaseOfAccess. In Kega Fusion, there are no settings to remove the menu bar, only when you press the shortcut keys Alt + Enter for toggle fullscreen mode, the menu bar disappear.

Rights About Emulators and Roms

You need to own games and consoles for having rights to use emulators and roms. You need to dump Bios of consoles and your games cards. Prefer a Nintendo Switch / Switch 2 to play games. It's very fun console with very fun games.

About Virus

You need to use Windows security to scan a folder. Everything I'm talking about, like my programs are free of virus. It depends where you download emulators and roms. Check everything before opening anything.

Playing with a Controller

You can choose a controller to play with an emulator from a nice diversity of controllers using SIGIL. I've already made some scripts and builds for it ready to use with emulators quoted here and simulating keys of keyboard from a Xbox controller. It's better than inner tool of the emulator because you can bind keys to more controller inputs, and it's ready to use. Also you will not have any conflict with your other games if you are using another controller without the need to unplug it.
