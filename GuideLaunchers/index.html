Launchers

Steam

  • Pros: There are a lot of games, you can stay playing without needing a console or any other plateform. The user interface is cool, and there are forums under steroids. If you play solo games, it's a must have. You can make good friends and have a nice profile. You can trade some contents. The games are not very expensive, you can redeem under 15 days and less than 2 hours played. There are nice solds and the wishlist is good. When you are using firewalls it's very good. The interface is also nice.
  • Cons: The plateform is unoptimized and bugged. You can't play multiplayer games because there are a lot of vulnerabilities. It need sometimes extra launchers. Games are not optimized. A lot of games appearing as scam and flooding the game library available under the store. It's also annoying to setup for all options.

EA App

  • Pros: Cool to play Battelefield, Apex, and other multiplayer games edited by Electronic Arts. The plateform is optimized.
  • Cons: Not as much games. Using firewalls is a mess. It's also annoying to setup for all options and the interface is ugly.

GoG Galaxy

  • Pros: Cool to play games with no digital right managements. The plateform is optimized. You can use firewalls. Games are not expensive. Nice browsing. There are nice solds and the wishlist is ok.
  • Cons: Not as much games. It's annoying to setup for all options and the interface is ugly.

Battle.Net

  • Pros: The plateform is optimized. Cool to play Call of Duty. It' very easy to setup, not as much options, but options are very good, and the interface is nice.
  • Cons: Only a few games. Using firewalls is a little mess sometimes.

Epic Games Launcher

  • Pros: Free games each week. A lot of games. Cool to play Fortnite, Rocket League, and other multiplayer games. When you are using firewalls it's good. The plateform is alsmost well optimized. There are nice solds and the wishlist is ok. It' very easy to setup, not as much options.
  • Cons: It need often extra launchers. Some annoying notifications and browsing can be hard. The interface is ugly.

Xbox App

  • Pros: A lot of games. The plateform is optimized. With PC game pass for solo games, it can be a good plateform, at least if you are ready to subscribe. There are nice solds and the wishlist is ok. Nice browsing. It' very easy to setup, not as much options.
  • Cons: You can't use any firewall. The games are not cheap if you don't subscribe to PC game pass. The interface is ugly.

UPlay

  • Pros: The plateform is optimized. Cool to play Ubisoft games. It' very easy to setup, not as much options.
  • Cons: Only a few games. An extra launcher by definition. Using firewalls is a mess. The interface is ugly.

Rockstars App

  • Pros: Cool to play only games edited by Rockstars. The plateform is optimized. Easy to setup.
  • Cons: Not as much games. Using firewalls is a mess. The interface is ugly.

Some Settings

  • Launch another exe through Steam:
    1. Right Click on your game.
    2. Go to Properties.
    3. Set Launch Options...
    4. Enter this command below:
    "FULL PATH TO GAME.EXE" %command%, i.e. "C:\Program Files (x86)\Steam\steamapps\common\Game\Game.exe" %command%
  • Launch directly a game through GoG Galaxy:
    Go into the game folder and copy the "Launch game name" file under your Desktop. Then you have a normal shortcut.
  • Launch directly a game through Battle.net:
    1. Create a shortcut to GAME.EXE and add the parameters after:
    “%filepath%\GAME.EXE” -username MyBnetEmail -password MyPassword -address na.actual.battle.net
    2. Replace na with eu or kr for the other regions for the argument parameter address.

My Simple Advices

  • Use only Steam to save and keep safe your library of games.
  • Never buy games implying another game launchers.
  • Use the dedicated game launcher for multiplayer games.
  • Don't trust third party centralized game launchers.
  • Take care to not subscribe for nothing.
  • Avoid consoles rip off.
