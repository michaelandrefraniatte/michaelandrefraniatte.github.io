ReactionResol

Chemical Reaction Resolution

Program for Equilibration of Chemical Reactions

This program is for automatically equilibrate reactions with 3 to 9 constituents, and can be used in conjunction with EoSResol to synthetize molecules with 8 atomes. Let's see...

Considerations About the Program

It can resolve every reactions in terms of number of products and reactants. It's nothing for I can making changes in derivative programs, or just one line text reaction program, because I made already the method to resolve every chemical reactions which are not to change in the program. To note, a molecule shall be written with each type of atome grouped in number. For example, a carbone C shall appear only one time on a line. To note, the first product, under the first line just after the equal sign, shall have a stoechiometric coefficient set to 1. I did that because scientific community consider it as impossible like a lot of things I did and prooved... Like the spontaneous generation of any molecule, and like resolution of polynomial equations with a hand pen using my mathematical hypothesis. To note, you must set dot instead of comma for number floating as decimal separator in regional options, under control panel. I made the web version of ReactionResol.
