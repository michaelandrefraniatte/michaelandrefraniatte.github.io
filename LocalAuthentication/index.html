Account Local Authentication for Open Program

I've made a method to authenticate locally a user for allowing to open a program. It need to authenticate the user and the computer used. Let's see...

Considerations About the Program

It's made for secure a program, but there is no control in real time for account maintenance, but instead if the user needs to use the program on another computer, it need a support. Get unique id from user. Get checksum from file. Get username from prefered and copy it on first line of la.txt. Create hash of the 3 and copy it on second line of la.txt. There are 3 textboxes, username, unique id, and the result of the hash to put on second line of la.txt. It's for check the hash in program and the hash in la.txt for local authentication.
