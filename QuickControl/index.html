QuickControl

Configure Controller Input

HID Competitive Configuration

This program is allowing to have a ready to use configuration for franchise of games. Let's see...

Considerations About the Program

Only what change from game to game for same franchise can be set. No need to rewrite a program. It's simple to use if you are a casual gamer and loving some franchise. It's minimal configuration for HID competitive gaming. It's made to adapt control at your needs when you change of game for a franchise. It's made to replace under better shape and design ciine. To note, for FPS gaming, the view sensitivity must be changed in game options because it depend of the performance of your PC, more your PC is high end, more it's sensitive so you must lower sensitivity. Also the response curve must be giving you the feeling to hold a gun, and it's like with a stick going to left or right from center and returning to center you making a half turn of the view. Try it by looking between two walls mirrored. For Wiimote, increasing sensitivity in the program is like going from 2 IR sources to 1 IR source, or just how you handle IR sources, but last version have several setting files for you to start, it just need to apply some changes in game options like deadzone to 0 and of course sensitivity. In fact aiming curve for right stick axis should be very progressive and large, but you can still change curve in game options between linear and standard, and an acceleration set to 0, and also a deadzone to 0 for right stick and 50 for left stick. Check my guide for some usefull information on setting controls. To note also, when you simulate a mouse move, increasing sensitivty make increase speed without bound, but you can bound it with a simple box applied with a condition for axis you emulate or simulate. So you can adapt everything to your liking. It's even more simple, truely and without any bug with SIGIL. For finish, I would saying it's far better than unbounding box line on the Nintendo Wii.
