Guide

Remote Play

Configuring Console Remote Play

To use any controller on console you need SIGIL for handle controller. For remote play you need to enable it under your console. To use remote play, you need a PC with XboxApp or Greenlight or XStreaming. This last program can be used with console display in 720p, otherwise only 1080p resolution is working. The remote play program you are using must be in front window but you can use an overlay in Topmost, enabling fullscreen with keyboard key F11. It need to enable a Xbox controller on your PC. You don't have any lag and it's more optimized when you using remote play if you set fullscreen mode toggle with F11 for your PC remote play application and setting the lowest resolution as possible for your PC device display from Windows parameters.

Using a Virtual Xbox Controller

You can play with any controller using SIGIL simulating a virtual Xbox controller, but you need to hide other controller from remote play program. The driver Devreorder is not working to hide controllers but HidHide program is working. You need to add remote play programs in HidHide program. It's the same steps as with Steam, but with remote play programs. If you want more workaround about HidHide, check my guide for it.

Disguarding About HidHide Versus About Soft Method

If you only play Xbox from your PC using remote play and not using it for PC gaming, it's important to know how you can script your games with SIGIL. If you start Xbox stream with xsrp with only a virtual Xbox controller and you have no other controller, and you don't restart xsrp, only your virtual Xbox controller will be recognized, even if you restart a stream, and even if you connect a controller after. So you can easy script a game with any controller that should not be taken by xsrp as default controller, but only your virtual Xbox controller. With SIGIL, it's important to know that you can loop the Scan method until the Scan method return true, implying your controller have just been detected by SIGIL, so you can firstly connect a virtual Xbox controller, start xsrp, start a stream, and then scan your controller, and only after connect your controller physically.

All It Working Now on Consoles

Following this guide lead you to make working any controller as a virtual Xbox controller on console. You can switch to screen of your console display for best gaming experience. Games in 720p are working better without any lag, and it secure in time your console. Also your PC used just for remote play feel better. It don't need a good PC, even a good network connection.
