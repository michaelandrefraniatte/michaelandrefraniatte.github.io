EmulatorAmbiLight

Overlay for Retro Gaming

Having Ambiant Colors

This program is allowing to have ambiant colors on each edge of screen as an overlay for emulator or wide screen. Let's see...

Considerations About the Program

I imagined this way to have a better experience with a famous SNES emulator. There's a param file to set your screen proportions and size of pixels. To note, the shortcut keys Alt + Enter is used to toggle fullscreen, the keys Page Down / Page Up are used to remove / add window title when the game is in foreground, also key Page Down is resizing and locating window, and also you can hide menu bar of emulator from the dedicated button under menu bar. Also, the shortcut keys Alt + Tab allow you to navigate between the window. To note also, you must set your task bar to hide automatically.
