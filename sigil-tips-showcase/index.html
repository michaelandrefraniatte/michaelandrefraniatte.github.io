II. Some Explainations for Gaming

It need to explain some tips for using a bunch of controllers in most of video games for it running as you expect.

  • Trick: In top down shooters or rail shooters, if there isn't any option to enable desktop cursor, setting the game in windowed mode, and removing the border if there isn't any option for windowed borderless mode, with WindowTitleRemover, it's possible to make running desktop cursor.
  • Controller Hiding: I've find my own workout to hide controllers by using HideDevice, and it's integrate to SIGIL libraries doing the job automatically when launching a script or an executable. And also, when you need to hide a DirectInput or a XInput controller, you must do it each time you plug your controller with the dedicated tool under this program, also you need to start a script or hide your controller before opening Steam. But there is a file named "hidedevicefromlist.txt" and an option to hide at run of the script your controllers you add (it's made for XInput and DirectInput controllers). And also, there is a file named "hideplusdevicenotfromlist.txt" and an option to hide plus at run of the script your controllers you don't add (it's made if Steam or games launch with administrative privilege).
  • Xbox Controller: You can motion aiming with gyroscope using Armor-X Pro from BigBigWon retailer, but it need a Android mobile with Bluetooth, WiFi, Localisation (GPS), all enable in your phone settings and firewall of your modem/router set to medium, and also it need to change some settings with the official application downloaded from Google store, despite a Playstation controller is far better. If you want more workaround about Armor-X Pro, check my guide for it.
  • Triggering Events: You need to install all drivers for it specifically for what you need, for simulate Keyboard and Mouse you need Interception and XNA, for Xbox Controller you need Scp, for PS4 Controller you need ViGEm, for Virtual Joystick you need VJoy, etc. See DriversInstaller.
  • K&M Simulation: You need to retrieve ID of keyboard and mouse from InterceptionTest, and for it you need to move mouse and press keyboard, also if you want to simulate several K&M, you need to connect several physical K&M to your PC.
  • Bluetooth Controllers: When launching a script, if your controller cannot be connected, restart the program or use the dedicated option to flush devices or with FlushDevices. Also, if using Joycon(s) 2 or Switch 2 Pro controller, you need to enable BLE (Bluetooth Low Energy) from the dedicated feature, to do just once for storing your BLE ID used on your PC, needed in Joycons 2 and Switch 2 Pro controller libraries. For connecting your controller via Bluetooth you can use InputPairing for it, or use the dedicated button.
  • Several Controllers: If the vendor ID or product ID isn't the same using same library with another instance for a second emulate controller, it's number is still 1, otherwise it's number is incremented (2), etc.
  • Some Bugs: Without sacrify the optimization, I'm unable to fix some bugs. Like if you disconnect nunchuck of Wiimote, there are no more data. And like, when you want to stop a process with a script showing dots, you need to manualy close the dots window from minimized window on task bar. Also, there's the story of message box appearing minimized but it need to read information and click "ok" to continue the process.
  • Compliant Solution: Before starting your game launcher, you need to run the process. It's particularly true with Steam and Epic Games Launcher because it handle some controllers. And also, anti-cheats don't like simulation such you need to avoid playing multiplayer games otherwise you will be shadow banned or life banned. We are here now, even if I never programed any cheat, and even if everyone are cheating. So prefer to use a tiny build or a tiny program like ciine.
  • Building Solution: Only FastColoredTextBox must be built in release Any CPU, but any other projects must be built in release x86. Otherwise it would not running.
  • Connecting Controllers: For connecting a Wiimote, you need to press the buttons 1 & 2 at same time. For connecting other Nintendo controllers, you need to press the sync button above the controller during 2 seconds. For connecting Playstation controllers, you need to press the buttons logo and create at same time during 2 seconds. The controllers have leds starting to blink when it's in pairing mode.
  • Using Voices: Check https://support.microsoft.com/en-us/windows/use-voice-recognition-in-windows-83ff75bd-63eb-0b6c-18d4-6fae94050571, for better experiments with voice recognition from your microphone.
  • Bluetooth Low Energy: Some old Bluetooth dongle have BLE (Bluetooth Low Energy) while new Bluetooth dongle haven't BLE and work badly to detect devices, some Bluetooth 4.0 dongle are ok for BLE and detecting well devices. If you have Bluetooth on your PC but Bluetooth Low Energy (BLE) don't run for handle to your BLE controllers you need to restart your PC.
  • Battletron Controllers: With the controller Playstation Battletron, for configure a back button, wire your controller, press the button near the back button you want to configure until your controller blinking, then press and release the button you want to assign to the back button, then press and release the button near the back button you want to configure. After that it's assigned which is indicate by a lite rumble of your controller.
  • Third Party Programs: Don't update the firmware of your controller with whatsoever sources, and don't use whatsoever third party programs for handle your controllers. When using a third party program for handle controllers, some data can not be retrieved at first start, but when you restart, the data can be retrieved.
  • Binding K&M: In game options, change key assignations, to remember easy which key to press and set mouse sensitivity to lowest as possible, for playing FPS having a fine aim in center, but still turn fast.
  • Wiimote IR Camera: Don't use a Wii or candles or Mayflash bar to task as IR source for the Wiimote but a USB Wii sensor bar, Wii Motion Plus extension for Wiimote is for having a gyroscope because Wiimote alone is having only a accelerometer, but if your Wiimote have already Wii Motion Plus inside, don't connect the extension, i.e. if you have Motion Plus builtin, don't insert Wii Motion Plus Extension, otherwise Nunchuck will not running.
  • Bluetooth Dongle: When using controllers via Bluetooth, you need to choose very well your Bluetooth adapter because it can be night and day. When you having a driver error for your Bluetooth dongle, avoid to check in device manager or devices and printers, but check your gamepad with joy.cpl instead, and restart your PC until you don't have anymore the driver error.
  • Connect Playstation Controllers: When you want to connect a Playstation controller, I advice you using PlayStationAccessoriesInstaller.exe to install the tool for Playstation accessories and have easy to connect Playstation controllers.
  • Motion Controls: When using Wiimote or Dualsense or custom motion controller, I advice to remove deadzone and add a securezone at the edge of view control to avoid unresponsive control, while removing the deadzone, take care to remove it just for the view not moving, when you almost not moving your aim, and with ADS of course.
  • K&M as Controller: When you are using mouse as a gamepad, if you control the view with mouse movements simulating a gamepad, you probably have a gaming mouse with a button above your mouse for increasing the DPI, as so you need to enable the highest DPI to avoid stuttering bug.
  • Controller Lagging: It's possible Bluetooth is lagging even on a brand new PC, if you have a internal Bluetooth device, it can lag with your controllers, but you can solve this issue with a Realtek Bluetooth 5.0 Adapter external device, you just have to uninstall the Bluetooth program from control panel under Programs and Features, and make a Bluetooth diagnostic and repair with the Windows tool for install the driver, and also devices connection through Bluetooth low energy can bug and not connecting if you don't disable your Bluetooth network card, and also install Bluetooth drivers. When you have issue with your controller via Bluetooth, you need to full charge it (7 hours connected via USB port of your PC). For charging your controllers, you need rechargeable batteries (type AA, NiMH, 1.5 Volts, x2), you need a charger with output of 5.0 Volts and maximum 1.5 Ampers (7.5 Watts), fast charge aren't handle (15 Watts) and breaking batteries, a PC USB port deliver the good energy for keep safe your batteries. When you using a controller wired, the wire shall allow both charge and synchronisation. When you need a cable for your controllers, you need cable allowing synchronisation (data) and power, often cable only allow power, but it needs both. For better performances, keep enable the service SysMain, and disable all bluetooth services but not the service bluetooth peripheral manager, for reduce input lag of your wireless controllers.
  • Gyro Aiming: For enabling gyroscope with Flydigi Vader 2 controller or Armor-X accessory to insert in a Xbox Series X controller, you must have the dedicated applications from official retaillers, otherwise it's not enable by default or too sensitive.
  • Anti-Cheat Issues: Some anti-cheats are detecting interception.dll as a cheat but in this case, there are other libraries to simulate keyboard and mouse, and you need to uninstall Interception driver manually. You can be shadow banned or worst definitively banned but these games don't deserve you.
  • Drivers Install: If you are using a virtual Xbox Controller, prefer to add manually the driver for it, install manually the driver as a driver for old generation device, choosing on disk with file .inf, from peripheral manager under control panel, it's in the tab system peipherals.
  • Games Handle: When you plug a physical controller and start a game, it recognize only this one, not the virtual one, it need to unplug it, and restart your PC.
  • Unconventional Issues: You can test your Xbox controller by typing joy.cpl from Run tool to open with the keyboard keys shortcut Windows + R, and also open control panel by typing it, and also control printers by typing it, and also audio settings by typing mmsys.cpl. Take care to bad wire and extended wire because it cause disconnection / reconnection in loop each second and can break your controller or USB storage device, prefer a long wire than using an extension. You cannot overclock Bluetooth peripherals but you can overclock USB peripherals. Unwire your controller each time you shut down your PC, and only wire it when your PC is on, and also remove batteries if you don't use it for a long time, otherwise old batteries can destroy your controller with acidity leak. If you don't have audio, when you using Dualshock4 or Dualsense via USB, the audio card recognize it, instead of your speakers by default, you need to disable it from audio card settings, i.e. when you connect a Dualshock4 or a Dualsense via USB, your sound card toggle to default the speakers of the controller, but you can simply disable it from sound card properties to revert the change (to do it only once, i.e. the first time). You games can run better in windowed borderless mode removing window title or if your third party tool to handle your controller is in system tray with notify icon.
  • Conventional Issues: When your game is running with administrative privilege, your third party programs interfering with your game, like for handle controllers, must running also like so. When you are using a automatic pairing for your Bluetooth controllers, if bugs occuring because your Bluetooth controllers disconnected badly, you have to connect/disconnect your Bluetooth controllers from peripherals and printers manager under control panel.
  • Being Competitive: If you want to be a competitive gamer in FPS, you need to set a sensitivity with ADS to 1:1, and if you are using gyro aiming, the sensitivity must be real world or more, i.e. a gamepad turn is a view turn with axis X, but you can check with axis Y.
  • Game Responsiveness: More a mouse have DPI more you can have a mouse sensitivity lowest in game options for same speed but with better fine aiming. For a game with x FPS, a polling rate of 2x for your mouse is enough. Removing border and window title like borderless fullscreen but decreasing game resolution in game options is a good choice.
  • Stick Drift and Calibration: There's a calibration each time you run a script after the prompt. So I don't advice to use any calibration gui tool from internet or inner program, because you can't reverse it, and with SIGIL it don't need.
  • Bluetooth Driver Error: If you have issue with your Bluetooth dongle like driver error under Bluetooth Windows settings, you need to disable Wireless Bluetooth from network card and from device manager under control panel.
  • Building Competitive Motion Gaming Controller: I have heard several times a person claiming that many of his ideas were taken or reused by companies such as Nintendo or Canal+.
