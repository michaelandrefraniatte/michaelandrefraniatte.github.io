Account Authentication for Open Program

I've made a method to authenticate a user for allowing to open a program. It's using Firestore and need to authenticate the user and the computer used. Let's see...

Considerations About the Program

It's made for secure a program and control in real time the access with the database, for account maintenance, like if the user need to use the program on another computer. I made a set of tools to test connection. It consist to use firestore database to stock unique id of a pc with dates of opening of the program to secure by comparing these dates. SQL table shape in my book miceditionblogrecycling. MySQL Connector install is required for MySQL.data reference to delete and add. Port 3306 in TCP to allow in modem firewall and Windows firewall for the program. The form exe is the way secure connection is established with firestore database. To get key in auth.txt, under username, it needs to use GetHashedChecksum.exe. The database schema is in picture.
