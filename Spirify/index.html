Spirify

Record Everywhere

Record Songs while You Listen to It

The program is made for capture audio from sound card for recording perfectly songs over whole internet. Any dev can make very simple tiny change to accomplish it everywhere. In less than 2 hours, it's done. Let's see...

Considerations About the Program

It stoping capture after the end of the current track, and restart before the next track, recording each time a song in a new file. It automatically records the file with the good name, and with tags like title and artist of song. To note, I made it because the method coming with STFU have been flagged as script injection, and the method coming with Spicify don't give any good result. So I had to search around for a robust solution. You need to allow download of several files, to change power plan to never shut down your screen and PC, and you have to always focus on the page listening music. Also, to avoid crash and bug, you need to disable the service Windows Defender using Autoruns in safe mode (WinDef never trust any function execution in every untrusted programs even for same function in loop).
