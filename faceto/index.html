Life isn't people, it's always good to know the truth, self learning have the last word at the end. Discharge your hate in the program, and know yourself. It's made for it. • Database with table Users to create in master database of local server using SQL.

Database structures using Google firestore as following:
• videoid: rand: videotitle, msg, author, date.
• list: videoid: videotitle.
