SIGIL

StandardInGamingInputLinker

HID Competitive Mapper

This program is allowing to have inputs of physical HID (Human Interface Device) and transfer to outputs of virtual HID for competitive and immerssive gaming. Let's see...

Considerations About the Program

I imagined this standard way, I named SIGIL (StandardInGamingInputLinker), for using gaming controllers in all PC games with highest level of optimization, even with a lot of HID handles. It correspond to a mix between ciine and StandardInGamingInputLite, but before I added the ability to create tiny standalone executable in StandardInGamingInputLite from script. It running as well as ciine but with modification on the fly. Also, a script is taking 50 times less space on your disk than a ciine program. As you can think, there are already several scripts available all running perfectly. But it's just a experimental purpose, because it's difficult and it take too much times to create scripts like that.

Available Scripts

  • K&M as Xbox controller
  • Wiimote as Xbox controller
  • Wiimote as K&M
  • Joycons as Xbox controller
  • Dualsense as Racing Wheel
  • Dualshock4 as Racing Wheel
  • Switch Pro controller as Racing Wheel
  • Joycon Charging Grip as Racing Wheel
  • and far more...
