KillcamCapture

Capture Your Killcam

An Optimized Recorder for Your Killcams

The program capture video and audio of your desktop and is optimized for killcam capture. The numpad key decimal (.) is used to start the capture, the numpad key 0 is used to stop it. Let's see...

Considerations About the Program

It's easy to use. It's just capturing every killcams in separate files and merge it. There's a params.txt file for set screen capture. You can check the process using PrintScreen and TextFromImage. Use paint to know the location under your screen.
