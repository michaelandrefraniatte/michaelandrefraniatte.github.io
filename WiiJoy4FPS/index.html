WiiJoy4FPS

Use Wiimote and Joycon in Games

Game Ready Wiimote and Joycon Support

The program is based on a concept of adaptative settings required for playing all games in a scripting interface. It come with a lot of scripts and books. Let's see...

Considerations About the Program

The program is made for being able to play your games using Wiimote and Joycon. After connected, leds stay blinking because it show naturally the level of batteries. For certain joycons like from freaks and geeks, you need to let pressed sync button until led blinking start to slow down and also you need to allow connection by clicking on Windows notification to connect it. There's a version of WiiJoy for CoD adapted for Joycon left from freaks and geeks corresponding to stick sensitivity, and another version with Joycon from Nintendo allowing to use values of a generic joystick, not allowed by Joycon from freaks and geeks.

If using this program as a driver for gaming, you need to know the information as following:
In CoD, enable controller instead of keyboard and mouse.
In Fortnite, in order to not meet view jumping, set mouse sensitivity to lowest values under game options, and remove all mouse and keyboard bindings.
