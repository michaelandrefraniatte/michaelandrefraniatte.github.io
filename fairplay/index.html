The program is a service to install helping to annoy cheaters in multiplayer games, i.e. flooding memory of a game process. Let's see...

Considerations About the Program

The service is made for flooding memory of process tasking as an unviversal anti-cheat. It contain a file where to set the name of process to flood. To note, the DLL must be copied under C:\Windows\System32 and C:\Windows\SySWOW64. And also, you need to enable the service to run automatically. If you want to choose the right platforms and games, check my guide for it. If you want to know how to recognize a cheater, check also my guide for it. Copy the file named dsm.dll under C:/Windows/System32 and C:/Windows/SySWOW64. Install the service with administrative privilege. After intalling the service, go to services configuration tab and set the service FairPlay to automatic start with delayed begin. Start the service FairPlay.
